# Learning first

Start with [learning path](learning-path.md), then read each concept before its phase. The deliverable is the ability to explain the system and its limitations, not just a running container. Every phase review includes an explain-back, one prediction made before measurement and one result that changed or confirmed the prediction.

The concepts cover prefill/decode, memory/KV, quantization and benchmark integrity. Scenarios cover concurrency OOM, misleading cache wins, quality regression and interrupted streams. [Interview questions](interview/questions-and-answers.md) provide answer criteria rather than scripts to memorize. No exercise here has been executed.
