# Definition of Done

A phase is COMPLETE only when its listed acceptance checks have evidence, the predecessor is approved, the reviewer understands the diff and the learner can explain the corresponding concept without reading implementation. Record a blocker alongside the current phase status when hardware or compatibility prevents the claim; never call a dry-run GPU benchmark passed.

Release requires: R1–R8 traced to passing checks or an explicitly approved scope change; pinned reproducible environment; complete benchmark protocol/results with honest uncertainties; approved model license; private auth and endpoint boundaries; no content/secret leakage; streaming/cancellation/overload tests; baseline and promoted profiles; successful recovery/rollback drill; no critical quality regression; updated architecture/ADRs/learning notes; clean repository and reviewed changes. Exact commands, environment, timestamps and evidence paths accompany results.

Production-grade here means disciplined contracts, observability, security and tested recovery for a single-host service. It does not claim HA, compliance certification, autonomous protection against prompt injection or enterprise multi-tenancy. Public publishing and infrastructure spending remain separate user decisions.
